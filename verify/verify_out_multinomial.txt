1. 口径 A 下的 E[Iss] 解析式
================================================================================
  E[Hbar]      = h(pi) - A - B + O(N^-2),   A=(K-1)/(2N),  B=(N-1)/(2N)*(<trP>-1)
  H_FSS^(A)    = h(pi) - A + O(N^-2)              [确定性部分]
  =>  E[Iss]   = 1 - B/(h(pi)-A)  + O(N^-2)
  A=(K-1)/(2N) 是有限-N 抽样项，在分子分母中【精确对消】。
  口径 B:  E[Iss] = 1 - (A+B)/h(pi)
  => 比值 = (h)/(h-A) * (1+O(N^-1))  = c
  N=16 均匀: A=0.093750  h=1.386294  H_A(exact)=1.285617  c=h/H_A=1.078310
  一阶近似 c ~ 1/(1-A/h) = 1.072531  (与精确差 0.54%)
  c (N=4,8,16,32,64) = 1.5106, 1.1896, 1.0783, 1.0361, 1.0174
