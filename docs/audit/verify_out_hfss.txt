5. DAMBE 打印的 Hmax 反推（汇总 §1.3 的旁证）
================================================================================
  口径 A 的 Hmax（bits）= h_bits(pihat) - (K-1)/(2N ln2) + O(N^-2)
    N= 4, h(pihat)=1.95 bits -> Hmax(A) = 1.409 bits
    N= 4, h(pihat)=1.80 bits -> Hmax(A) = 1.259 bits
    N= 8, h(pihat)=1.95 bits -> Hmax(A) = 1.679 bits
    N= 8, h(pihat)=1.80 bits -> Hmax(A) = 1.529 bits
    N=16, h(pihat)=1.95 bits -> Hmax(A) = 1.815 bits
    N=16, h(pihat)=1.80 bits -> Hmax(A) = 1.665 bits
    N=32, h(pihat)=1.95 bits -> Hmax(A) = 1.882 bits
    N=32, h(pihat)=1.80 bits -> Hmax(A) = 1.732 bits
  汇总称 DAMBE 打印 1.65–1.85 bits（N<=32）-> 与 N=16/32 行的口径 A 相符；
  但 N=4 时口径 A 会低到 ~1.4 bits，故该旁证只能在 N 较大时成立。
